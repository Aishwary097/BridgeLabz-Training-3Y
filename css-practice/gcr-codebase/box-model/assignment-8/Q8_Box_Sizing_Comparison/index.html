One declaration, two outcomes

The width
you set.

Both examples declare the same width and padding. The box-sizing rule decides whether the border joins that measurement or grows beyond it.

01 / DEFAULTCONTENT-BOX

Content-box

The width applies to content alone. Padding and border are added outside it.

Declared width: 220px+ padding + border
CONTENTwidth: 220px
Actual outer width284px
02 / BORDER-BOXINCLUDED

Border-box

The declared width includes content, padding, and border inside one boundary.

Declared width: 220pxAll layers included
CONTENTwidth: 220px total
Actual outer width220px
↳

Border-box makes layouts easier to size because the width you declare is the width you get.
