A few foundations worth remembering

Let the page
stay flexible.

Three useful principles for layouts that adapt with their content and the space around them.

01 / SIZING↔

Fluid layouts

Use flexible values so columns can grow and shrink with their container instead of relying on one fixed width.

MAIN WIDTHwidth: min(100%, 72rem);
MAKE SPACE FOR CONTENT
02 / ASSETS◫

Flexible media

Keep images and other media inside their layout so they scale without spilling past the page.

IMAGE RULEmax-width: 100%;
KEEP MEDIA IN FLOW
03 / CHANGE⌁

Breakpoints

Add a media query when the current layout no longer gives the content enough room.

SMALL SCREENS@media (max-width: 600px)
RESPOND WHEN IT HELPS
