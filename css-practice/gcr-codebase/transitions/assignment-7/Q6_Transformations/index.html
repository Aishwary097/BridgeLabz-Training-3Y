Four ways to change perspective

Move a shape.
Change the story.

Each tile begins still. Hover to rotate, scale, translate, or skew it into a new position.

01

Rotate

transform: rotate(12deg)

Turn the element around its center.

02

Scale

transform: scale(1.14)

Grow the element without changing its flow.

03

Translate

transform: translate(12px, -10px)

Shift the element along both axes.

04

Skew

transform: skew(-10deg)

Lean the element along its horizontal axis.
